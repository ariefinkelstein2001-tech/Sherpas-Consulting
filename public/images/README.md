# Fotos del sitio

Sube aquí las fotos con **exactamente estos nombres** y aparecerán solas en el
sitio (mientras no existan, se muestra un placeholder cálido, nada se rompe).

| Archivo | Dónde aparece | Orientación | Proporción |
|---|---|---|---|
| `hero-principal.jpg` | Hero (foto grande) | Vertical (retrato) | 4:5 |
| `hero-taller.jpg` | Hero (foto chica) | Cuadrada | 1:1 |
| `equipo.jpg` | Sección Propósito | Vertical (retrato) | 4:5 |
| `taller-banda.jpg` | Banda ancha (opcional) | Horizontal | 16:9 |

**Recomendaciones**
- Formato `.jpg` o `.webp`. Peso ideal < 400 KB cada una (optimízalas antes de subir).
- Buena luz, fotos reales de personas/equipo/talleres → el "corte" luminoso y humano.
- Si quieres cambiar los nombres o agregar más, edita `src/data/images.ts`.

> Las rutas están centralizadas en `src/data/images.ts`.
